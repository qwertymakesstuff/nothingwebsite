## Pages per site
**Findr** — `/` home (search, Lucky Dip, browse categories, trending), `/search?q=&type=all|video|forum|people|social&time=any|week|month|year|older&site=&p=`, `/trends`, `/history`, `/about`, `/privacy`, site 404.
**Vidder** — `/`, `/trending?cat=`, `/results?search_query=&sort=date|views`, `/watch?v=&list=&t=`, `/channel/ID[/videos|/playlists|/about]?sort=popular`, `/playlist?list=` (incl. `WL`, `FAV`), `/subscriptions`, `/history`, removed-video and 404 pages.
**Threadit** — `/?sort=hot|new|top`, `/communities`, `/c/NAME?sort=&p=`, `/c/NAME/t/ID?sort=best|new|old`, `/u/NAME?tab=overview|posts|comments`, `/search?q=&c=`, `/archive?c=`, 404.
**Blink** — `/` (sign-up, then feed), `/trending`, `/find?q=`, `/USER[/about|/following|/followers|/photos]`, `/me`, `/post/ID`, `/notifications`, `/settings`, 404.
