## How to use
1. Paste a prompt into Midjourney. Pick the best of the four, upscale, download.
2. Drop the download into `tools/fakeos-media/inbox/`. Renaming it to the **file name** shown is safest; the importer also recognises Midjourney's own file names.
3. Run `node tools/fakeos-media/import-images.mjs`. It shrinks each image to a small WebP in `fakeos/media/`, keeps the original in `tools/fakeos-media/originals/`, and updates the game's media list.
4. Reload FAKEOS. Anything you haven't made yet keeps its drawn version.

Optional for videos: a Midjourney still saved as `still-<videoId>-<shot>.png` (e.g. `still-gBforlater0-1.png`) in the inbox becomes the first frame of that shot, which keeps people consistent.

Skipped on purpose: hollowfrequency, q_mardell (anomaly accounts keep the default blank avatar), Vidder (brand mark), passers-by (drawn avatars), the player's own Blink picture.
