# FAKEOS

A computer from 2013 and the internet that comes with it. Open `fakeos/index.html` through any static web server (it is served at missing.website/fakeos/).

- Docs: `docs/` (start with GAME_DESIGN.md and TECHNICAL_ARCHITECTURE.md)
- Tests: `node --test tests/music/fakeos.test.mjs` from the repository root
- Content lives in `js/content/`; add videos, threads or posts there and the sites pick them up.
