# SkinSpin (`/skinspin/`)

A case-opening simulator with original, fictional weapon skins and fictional coins. Plain HTML,
CSS and ES modules, no build step, no dependencies. Built in phases; done so far: **Phase 1**
(website foundation, item database and case catalogue, case opening, inventory) and **Phase 2**
(upgrades, trade-up contracts and collections, case battles, simulated marketplace).

The $ balance is play money only: there is no way to buy it, deposit into it or cash it out.

## Rules the code keeps

- Every transaction in `economy.js` validates first and mutates second, so a failed one changes
  nothing. Coins can't go negative, a sale can't include a missing, duplicated or locked item,
  and bulk sales skip favourites unless the player includes them.
- Opening a case charges, rolls and adds the item in one step **before** the roulette is built.
  The strip is laid out around that item and the animation only travels to it.
- The odds panel is generated by `caseOdds()`, which reads the same weights and pools `rollCase()`
  draws from. Each rarity's chance is split evenly between its items.
- Every item that enters the inventory goes through `acquireItem()` (cases, upgrades, contracts,
  battles, market), and everything that consumes items goes through `checkConsumable()`, which
  refuses missing, duplicated and locked items. A listed market item leaves the inventory until it
  sells or is cancelled, so it can't be used anywhere else meanwhile.
- Upgrades, contracts and battles are settled in one transaction before their animations play.
  The upgrade needle stops at the roll that was drawn; battles replay the stored result.
- Battle reward rule: winner takes all; ties go to the best single item, then a random draw. NPCs
  draw with `rollCase()` from the same random stream as the player.
- Market prices are SkinSpin's own simulation, held within ±15% of item value; not real prices.
- The cases and the Mill Street items come from the asset archive: names, rarities, values and each
  case's item list follow its CaseForge catalogue (values divided by 10, rarities shifted onto
  SkinSpin's tiers: Common = Industrial ... Mythic = Extraordinary). Each case also carries themed
  collections from the original catalogue so all 147 items stay obtainable.
- The save is one JSON object with a `version`. Anything unreadable is copied to a backup key
  first; damaged fields are repaired one by one; saves from a newer version are backed up before loading.
  Version 3 rewrote the original 15 case ids to the archive cases that replaced them.
